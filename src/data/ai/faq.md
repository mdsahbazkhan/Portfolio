## Generative AI

### What is RAG?

RAG stands for Retrieval-Augmented Generation. It combines information retrieval with an LLM so that relevant external information can be retrieved and provided as context before generating an answer.

### How has Sahbaz used RAG?

Sahbaz implemented a RAG workflow in Velquix. The documented pipeline includes:

```text
PDF
 ↓
Text Extraction
 ↓
Text Chunking
 ↓
Embeddings
 ↓
ChromaDB
 ↓
Semantic Retrieval
 ↓
Relevant Context
 ↓
LLM
 ↓
Generated Answer
```

### What vector database has Sahbaz used?

Sahbaz has used ChromaDB in Velquix for storing and retrieving document embeddings.

### What embedding technology has Sahbaz used?

Sahbaz has used HuggingFace Embeddings in Velquix to convert document chunks into vector representations.

### What LLM has Sahbaz used?

Sahbaz has used Groq Llama 3.3 in Velquix for generating responses using retrieved document context.
