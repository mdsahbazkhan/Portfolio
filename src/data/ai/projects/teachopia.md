# Teachopia

## Project type

Learning Management System (LMS).

## Context

Teachopia is an LMS project that Sahbaz worked on during his internship at Kognito Kube. His work focused primarily on frontend development and REST API integration.

## Overview

Teachopia is an LMS platform designed to provide users with an interface for managing and accessing academic and course-related information.

During the internship, Sahbaz contributed to the frontend application and integrated backend REST APIs to display and manage data through the user interface.

## API integration

A major part of Sahbaz's contribution was integrating REST APIs into the frontend. The frontend consumed backend APIs to retrieve and display application data.

The general workflow was:

```text
User Interaction
      ↓
Next.js / React Frontend
      ↓
API Request
      ↓
Backend REST API
      ↓
API Response
      ↓
Redux / Component State
      ↓
UI Update
```

Sahbaz's responsibility was primarily on the frontend side of this workflow, including consuming API responses and integrating the returned data into the user interface.
